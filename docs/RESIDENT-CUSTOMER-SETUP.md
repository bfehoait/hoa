## Manual acceptance checklist

- Resident home shows announcements/security before account information. No unconnected amount reads as zero or settled.
- Registration submits into the office inbox. Staff can inspect optional household information; another resident and an anonymous reader cannot read it. Approval creates one linked account and marks one application Approved. Rejecting an application creates no account. Repeated submission does not create duplicates. Staff verify identity and residence outside the form; public email submission is not proof of ownership.
- Each pass type can be requested for an approved lot, reviewed and acted on by authorized security. A resident cannot approve a pass, release another household's pass or bypass expiry/lot restrictions. Gate outbound release works without an entry event. Invalid plates/time/party/item fields are refused by the server.
- Amenity selectors exclude occupied/past times, require end after start and stay within configured hours and 7 AM–10 PM. Office can approve/reject; resident can cancel only when permitted. Empty configuration directs the resident to the office; use approved actual amenities, not the synthetic seed on a live project.
- Livelihood shows only published, unexpired, audience-eligible listings. Search/category pagination works. No seller email/private answer leaks through the new metadata read. Photos/contact links follow existing review rules.
- Documents have a truthful empty/error state. Authorized staff attach a PDF to a Submitted board-record, review then publish it to the appropriate audience. Resident view/download succeeds only for a permitted published document. Unpublished, expired, withdrawn and wrong-audience files are denied; tokens/links expire. Attachments are PDF-only, at most 10 MB. Uploading a PDF changes the record version so stale review should be rejected. File replacement/version-retirement remains a separate follow-up; create a new document record for a new version.
- Existing permit forms still submit and appear in office review. The approved permit requirements/fees are not inferred from the old application.
